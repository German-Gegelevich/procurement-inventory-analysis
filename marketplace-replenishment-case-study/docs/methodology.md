# Методика

## Источник и границы

Рабочая книга содержит несколько десятков листов по ассортименту, продажам, рекламе, рейтингам и остаткам на маркетплейсах. Для воспроизводимого примера выбран лист `Анабар Озон год`: в нём есть идентификаторы товара, категория, остатки, продажи в штуках в день и поле рекомендации поставки.

Исходный файл не входит в публичную историю Git. Для проверки пайплайна используется небольшой синтетический CSV с теми же смысловыми полями.

## Этапы обработки

1. Читаются только нужные столбцы.
2. Числовые поля приводятся к числовому типу; некорректные значения становятся пропусками.
3. Строки без продаж в день получают пустое покрытие.
4. Рассчитываются покрытие, флаг риска и дополнительный разрыв к рекомендации.
5. Для сводки записи агрегируются по категории; SKU, штрихкоды, названия и бренды не попадают в итоговый файл.

## Интерпретация

- **Покрытие ниже 7 дней:** потенциально срочная позиция, если срок пополнения превышает оставшиеся дни запаса.
- **Высокая рекомендованная поставка:** требует сверки с бюджетом, сезонным спросом и доступностью товара у поставщика.
- **Покрытие пустое:** продажи равны нулю либо отсутствуют; это не означает, что запасов достаточно.

Показатели предназначены для приоритизации проверки, а не для автоматического размещения заказа.
