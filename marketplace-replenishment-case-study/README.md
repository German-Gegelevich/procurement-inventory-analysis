# Кейс: анализ остатков и пополнения на маркетплейсах

Дополнительный кейс к проекту по планированию запасов: обработка книги операционной аналитики Wildberries и Ozon, с расчётом покрытия товара и приоритетов пополнения. В открытом репозитории размещены только синтетические демонстрационные данные.

> **Конфиденциальность:** исходный файл и реальные товарные показатели не размещаются в открытом репозитории. Полная исходная книга сохранена отдельно в архиве проекта. Для работы с ней используйте локальный запуск скрипта.

## Задача

Свести данные об остатках и темпе продаж в понятную таблицу для решения о пополнении: какие позиции рискуют закончиться, какой запас уже доступен и какой объём рекомендуется поставить.

## Что сделано

- изучена структура большой книги: листы с динамикой продаж, рейтингами, рекламой, запасами по складам и прогнозом потребности;
- подготовлена воспроизводимая обработка Ozon-листа «Анабар Озон год»;
- рассчитаны дни покрытия запасом, риск дефицита и разрыв между рекомендацией поставки и текущим остатком;
- добавлена сводка по категориям без идентификаторов конкретных товаров;
- включён безопасный демонстрационный CSV с вымышленными данными.

## Показатели

| Показатель | Расчёт |
|---|---|
| Покрытие запасом, дни | Остаток на Ozon / продажи в день |
| Риск дефицита | Покрытие меньше порога в 7 дней |
| Рекомендуемая поставка | Значение из исходного поля «Необходимо поставить, шт.» |
| Разрыв рекомендации | max(рекомендация − текущий остаток, 0) |
| Доля позиций с риском | Позиции с покрытием ниже порога / все позиции категории |

Нулевой темп продаж получает пустое значение покрытия, чтобы не делить на ноль. Строки без категории или числовых значений приводятся к безопасным значениям до агрегации.

## Быстрый старт

Требуются Python 3.10+ и Excel-файл `.xlsx`.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

Для демонстрации на синтетических данных:

```bash
python src/replenishment_analysis.py --input data/sample/anonymized_sample.csv --format csv --output-dir outputs/demo
```

Для обработки сохранённой книги:

```bash
python src/replenishment_analysis.py --input "путь/к/рабочей-книге.xlsx" --sheet "Анабар Озон год" --output-dir outputs/local_analysis
```

Скрипт создаёт `products.csv` и `category_summary.csv`. Локальные выходные файлы исключены из Git. Перед публикацией не добавляйте исходную книгу, выгрузки маркетплейсов или результаты анализа с реальными цифрами.

## Как использовать результаты

1. Откройте `category_summary.csv` и отсортируйте категории по доле позиций с покрытием менее 7 дней.
2. Проверьте товары с высоким рекомендуемым объёмом поставки.
3. Сверьте рассчитанный риск с ограничениями по бюджету, сроком поставки и остатками у поставщика.
4. Не используйте рекомендацию автоматически: перед заказом проверьте актуальность исходных остатков и сезонность.

## Ограничения

- пример данных синтетический и не отражает результаты конкретного продавца;
- исходный лист является снимком состояния на дату выгрузки; обновление книги требует повторного запуска;
- рекомендации из источника сохраняются как исходные значения и не подменяются собственным прогнозом;
- порог риска 7 дней — настраиваемый параметр, а не универсальная норма.
