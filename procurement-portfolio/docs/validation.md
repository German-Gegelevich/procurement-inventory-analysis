# Выполненная проверка

1. Исходная книга прочитана; экспортированы только её синтетические таблицы.
2. Получены 240 товаров, 7 200 дневных продаж и 480 складских остатков.
3. SQL выполнен на SQLite; все ключи и внешние связи прошли проверку.
4. Все 240 SKU сверены с Excel по количественным показателям, бюджету и статусам.
5. Проверены положительный заказ не меньше потребности, минимальная партия и кратность.
6. Репозиторий не содержит реальных исходных рабочих файлов, таблицы соответствия идентификаторов или учётных данных.

Python-скрипт повторяет проверки структуры и ограничений заказа при каждом запуске. Полная сверка с Excel выполнена при подготовке проекта; для запуска анализа Excel-библиотеки не требуются. Поведение настольного Excel не тестировалось.
