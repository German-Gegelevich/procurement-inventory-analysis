# Герман — портфолио аналитика закупок

**SQL · Excel · Планирование товарных запасов**

## Планирование закупок и запасов Wildberries

Учебный проект на полностью синтетических данных за **сентябрь 2026 года**. Задача — определить приоритеты пополнения товаров и рассчитать объём заказа с учётом продаж, запасов, входящих поставок, сроков пополнения и ограничений партий.

![Результаты анализа](procurement-portfolio/assets/overview.png)

### Результаты учебного сценария

- Проанализированы **240 SKU** и **7 200 ежедневных наблюдений продаж**.
- У **129 SKU** запас меньше срока пополнения; требуется проверка риска дефицита.
- **46 SKU** превышают принятый порог запаса.
- Модель рекомендует пополнить **136 SKU**.
- Расчёты SQL сверены с Excel по всем 240 товарам.

Это расчётная модель, а не подтверждённый эффект внедрения. Все показатели и названия вымышлены.

### Запуск анализа

После скачивания или клонирования репозитория перейдите в папку проекта:

```bash
cd procurement-portfolio
python scripts/run_analysis.py
```

Нужен Python 3.10+; сервер базы данных и дополнительные пакеты для SQL-анализа не требуются. Для обновления графика нужен matplotlib; инструкция находится в описании проекта.

Проект подготовлен с помощью ChatGPT. Синтетические данные позволяют показать подход к аналитике без раскрытия коммерческой информации.
